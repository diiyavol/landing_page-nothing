
# 🖤 Nothing - Landing Page

> A small, minimalist landing page designed for presentations, showcasing the features of a flagship product. ✨


## 🛠️ Technologies Used

This project was built using a modern web technology stack:

- **HTML5 and CSS3**: For creating a responsive, semantic, and stylish page structure.
- **Sass (SCSS)**: A preprocessor for writing clean, modular, and maintainable CSS (using variables, nesting, and mixins).
- **Node.js**: For server-side development and running JavaScript on the server.
- **NPM**: For managing project dependencies and scripts.
- **Git and GitHub**: For version control, tracking changes, and hosting the repository.

## Technical Requirements
To run this project, you will need:

- Node.js (version 20.x or newer): A JavaScript runtime built on Chrome's V8 JavaScript engine, used for server-side scripting.
- NPM (version 11.x or newer): The Node.js package manager, used for managing project dependencies.

## 💻 Getting Started (Run Locally)

Clone the project

```bash
  git clone https://github.com/diiyavol/landing_page-nothing.git
```

Go to the project directory

```bash
  cd landing_page-nothing
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run start
```

After starting the project, it will be available at http://localhost:8080. You can use this URL to preview the landing page and ensure it displays correctly. You can also make changes to the project files and see updates in real-time.
